# Отладчик односвязных списков

Два файла, которые работают без сервера и без установки:

- `index.html` — отладчик произвольного кода на C++ со списками
- `basic.html` — отладчик одной функции (удаление элементов меньше предыдущего)

Внешних библиотек нет, интернет для работы не нужен. Любой из способов ниже превращает папку в сайт со ссылкой.

## Способ 1. GitHub Pages (бесплатно, ссылка вида имя.github.io/репозиторий)

1. Создай на github.com новый публичный репозиторий, например `list-debugger`.
2. Нажми «Add file», затем «Upload files», перетащи `index.html` и `basic.html`, нажми «Commit changes».
3. Открой «Settings», затем «Pages».
4. В поле «Branch» выбери `main` и папку `/ (root)`, нажми «Save».
5. Через минуту-две сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/list-debugger/`.

То же из терминала:

```bash
git init
git add index.html basic.html README.md
git commit -m "Add list debugger"
git branch -M main
git remote add origin https://github.com/ТВОЙ-ЛОГИН/list-debugger.git
git push -u origin main
```

## Способ 2. Netlify Drop (самый быстрый, без регистрации на пробу)

1. Открой app.netlify.com/drop.
2. Перетащи в окно всю папку `site`.
3. Сайт сразу получит ссылку. Если зарегистрироваться, ссылку можно сохранить и переименовать.

## Способ 3. Cloudflare Pages или Vercel

Подключи тот же репозиторий с GitHub. Сборка не нужна: в качестве команды сборки оставь пустое поле, в качестве папки с результатом укажи корень.

## Способ 4. Просто отправить файл

Файл `index.html` можно отправить в мессенджер или на почту, получатель откроет его двойным щелчком в любом браузере.
